# Job Application MERN Stack Website

## Features
- Applicant: View/filter/search jobs, apply to jobs, view applied jobs and status
- Employer: Post jobs, view applicants, select applicants, change application status
- Authentication and user roles

## Structure
- `server/` - Node.js/Express backend
- `client/` - React frontend

## Getting Started

### Backend
1. `cd server`
2. `npm install`
3. Set up MongoDB and update `.env` if needed
4. `npm run dev`

### Frontend
1. `cd client`
2. `npm install`
3. `npm start`
